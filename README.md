# Tactica Website

This is the public website for Tactica — AI-powered tactical intelligence for football.

## Overview

Tactica analyzes real match data, scores every formation through a trained machine learning model, and tells you exactly how to line up — for any club, any nation, completely free.

## Features

- **Auto-Tactics**: Fetches each team's last 5 matches, extracts formations played, computes live attack/defense ratings, and recommends optimal game plans
- **Opponent Analysis**: Compare two teams head-to-head with tactical guidance
- **Coach's Sandbox**: Test your own formations and get win probability estimates
- **Live Simulator**: Get situation-specific advice based on match minute and scoreline
- **AI Tactical Chat**: Live-aware assistant manager that knows your squad
- **World Cup 2026 & Nations League**: Full coverage of 86 nations — World Cup qualifiers and UEFA Nations League participants
